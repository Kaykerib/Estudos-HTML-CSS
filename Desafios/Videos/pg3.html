O Curso em Vídeo (@cursoemvideo) é um canal brasileiro de ensino de programação, criado pelo professor Gustavo Guanabara. A descrição diz que é um dos maiores canais educacionais de programação do YouTube, com cursos gratuitos em videoaulas para quem quer aprender tecnologia do zero.

  • Algoritmo
  • PHP
  • Java
  • JavaScript
  • Python
  • HTML5 e CSS3
  • Git
  • MySQL e Banco de Dados

Quem quiser certificado precisa estudar pela plataforma online deles, onde também dá para comprovar o conhecimento em entrevistas e complementar as horas de estudo. Para patrocínios, palestras e parcerias, o contacto é comercial@cursoemvideo.com.
